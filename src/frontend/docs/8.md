# Writeups System API

## Writeup Model

```typescript
interface Writeup {
	id: number;
	title: string;
	content: string; // Markdown
	summary?: string;
	challenge_name: string;
	challenge_category:
		| "web"
		| "crypto"
		| "pwn"
		| "reverse"
		| "forensics"
		| "misc";
	contest: Contest;
	author: User;
	team?: Team;
	difficulty_rating: number; // 1-10
	quality_rating: number; // Average from user ratings
	tags: string[];
	is_public: boolean;
	is_featured: boolean;
	view_count: number;
	like_count: number;
	created_at: string;
	updated_at: string;
	published_at?: string;
}

interface WriteupComment {
	id: number;
	content: string;
	author: User;
	writeup_id: number;
	parent_id?: number; // For replies
	created_at: string;
	updated_at: string;
}
```

## API Endpoints

### GET /api/writeups

**Query Params:**

- `page=1` `limit=12`
- `search=challenge_name`
- `category=web`
- `contest_id=123`
- `author_id=456`
- `team_id=789`
- `difficulty_min=5` `difficulty_max=8`
- `featured=true`
- `sort_by=newest|popular|rating`

**Output:**

```json
{
	"success": true,
	"data": {
		"writeups": [
			{
				"id": 123,
				"title": "SQL Injection in Admin Panel",
				"summary": "Exploiting blind SQL injection vulnerability",
				"challenge_name": "Admin Portal",
				"challenge_category": "web",
				"contest": {
					/* Contest object */
				},
				"author": {
					/* User object */
				},
				"team": {
					/* Team object */
				},
				"difficulty_rating": 7,
				"quality_rating": 4.5,
				"tags": ["sql", "blind", "time-based"],
				"view_count": 1234,
				"like_count": 89,
				"created_at": "2024-01-15T10:00:00Z"
			}
		],
		"total": 156,

}
```

### POST /api/writeups

**Headers:** `Authorization: Bearer <token>`
**Input:**

```json
{
	"title": "Buffer Overflow in Login Service",
	"content": "# Challenge Overview\n\nThis writeup covers...",
	"summary": "Exploiting stack buffer overflow",
	"challenge_name": "Login Service",
	"challenge_category": "pwn",
	"contest_id": 456,
	"team_id": 789,
	"difficulty_rating": 8,
	"tags": ["buffer-overflow", "stack", "ret2libc"],
	"is_public": true
}
```

**Output:**

```json
{
	"success": true,
	"data": {
		/* Created Writeup object */
	}
}
```

### PUT /api/writeups/:id

**Headers:** `Authorization: Bearer <token>`
**Input:** Same as POST
**Output:**

```json
{
	"success": true,
	"data": {
		/* Updated Writeup object */
	}
}
```

### DELETE /api/writeups/:id

**Headers:** `Authorization: Bearer <token>`
**Output:**

```json
{
	"success": true,
	"message": "Writeup deleted"
}
```

### POST /api/writeups/:id/like

**Headers:** `Authorization: Bearer <token>`
**Output:**

```json
{
	"success": true,
	"data": {
		"liked": true,
		"like_count": 90
	}
}
```

### POST /api/writeups/:id/rate

**Headers:** `Authorization: Bearer <token>`
**Input:**


**Output:**

```json
{
```

### POST /api/writeups/:id/comments

**Headers:** `Authorization: Bearer <token>`
**Input:**

```json
{
	"content": "Excellent writeup!",
	"parent_id": 456 // Optional, for replies
}
```

**Output:**

```json
{
	"success": true,
	"data": {
		/* Created Comment object */
	}
}
```

### GET /api/writeups/featured

**Output:**

```json
{
	"success": true,
	"data": [
		/* Featured Writeup objects */
	]
}
```

### GET /api/writeups/trending

**Query:** `period=week|month`
**Output:**

```json
{
	"success": true,
	"data": [
		/* Trending Writeup objects */
	]
}
```

### POST /api/writeups/:id/report

**Headers:** `Authorization: Bearer <token>`
**Input:**

```json

	"description": "Contains offensive language"
}
```

**Output:**

```json
{
	"success": true,
	"message": "Report submitted"
}
```
