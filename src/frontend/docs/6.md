# Leaderboard & Statistics API

## Models

```typescript
interface LeaderboardTeam {
	place: number;
	name: string;
	country: string;
	total_points: number;
	contests_won: number;
	monthly_points: number;
	is_verified: boolean;
	members: number;
	rating_history: RatingPoint[];
}

interface PlatformStats {
	ranked_teams: number;
	team_members: number;
	active_contests: number;
	past_events: number;
}

interface TeamStatistics {
	contests_participated: number;
	contests_won: number;
	total_points: number;
	average_rating: number;
	best_ranking: number;
	current_rating: number;
	rating_history: RatingPoint[];
}
```

## API Endpoints

### GET /api/leaderboard/teams

**Query Params:**

- `limit=20`
- `country=US`
- `verified_only=true`

**Output:**

```json
{
	"success": true,
	"data": [
		{
			"place": 1,
			"name": "r3kapig",
			"country": "CN",
			"total_points": 1020.905,
			"contests_won": 5,
			"monthly_points": 250.3,
			"is_verified": true,
			"members": 8,
			"rating_history": [
				{
					"date": "2024-01-15",
					"rating": 1020.905,
					"contest": "CyberChallenge 2024"

```
