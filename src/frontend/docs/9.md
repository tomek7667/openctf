# File Upload & Media Management API

## File Upload Model

```typescript
interface UploadedFile {
	id: string;
	filename: string;
	original_name: string;
	mime_type: string;
	size: number;
	url: string;
	thumbnail_url?: string;
	uploaded_by: number; // User ID
	entity_type:
		| "user_avatar"
		| "team_logo"
		| "contest_logo"
		| "contest_banner"
		| "writeup_image";
	entity_id: number;
	created_at: string;
}
```

## API Endpoints

### POST /api/upload/avatar

**Headers:** `Authorization: Bearer <token>`
**Content-Type:** `multipart/form-data`
**Input:**

- `file`: Image file (max 5MB, jpg/png/gif)
  **Output:**

```json
{
	"success": true,
	"data": {
		"id": "upload_123",
		"url": "https://cdn.openctf.com/avatars/user_123.jpg",
		"thumbnail_url": "https://cdn.openctf.com/avatars/user_123_thumb.jpg"
	}
}
```

		"filename": "user_123.jpg",

### POST /api/upload/bulk

**Headers:** `Authorization: Bearer <token>`
**Content-Type:** `multipart/form-data`
**Input:**

- `files[]`: Multiple files
- `entity_type`: Target entity type
- `entity_id`: Target entity ID
  **Output:**

```json
{
	"success": true,
	"data": {
		"uploaded": [
			{
				"id": "upload_301",
				"url": "https://cdn.openctf.com/bulk/file1.jpg"
			}
		],
		"failed": [
			{
				"filename": "invalid.exe",
				"error": "Invalid file type"
			}
		]
	}
}
```

## File Processing

### Image Processing

- **Avatars**: Resize to 256x256, generate 64x64 thumbnail
- **Team Logos**: Resize to 512x512, generate 128x128 thumbnail
- **Contest Logos**: Resize to 400x400
- **Contest Banners**: Resize to 1200x300
- **Writeup Images**: Max 1920px width, maintain aspect ratio

### File Validation

- **Allowed Types**: jpg, jpeg, png, gif
- **Size Limits**:
  - Avatars/Logos: 5MB
  - Banners/Writeup Images: 10MB
- **Dimensions**: Minimum 100x100 for logos/avatars
- **Security**: Virus scanning, metadata stripping

### Storage

- **CDN**: CloudFront/CloudFlare distribution
- **S3**: Primary storage with versioning
- **Backup**: Cross-region replication
- **Cleanup**: Orphaned file detection and removal
