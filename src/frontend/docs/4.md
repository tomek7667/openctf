# Contests Management API

## Contest Model

```typescript
interface Contest {
	id: number;
	name: string;
	description?: string;
	rules?: string;
	prizes?: string;
	start: string;
	end: string;
	url?: string;
	ctftime_id?: number;
	assigned_weight_points: number;
	logo?: string;
	organizers?: Team;
	places?: Place[];
	status: "upcoming" | "ongoing" | "finished" | "cancelled";
	// Extended fields
	format: "jeopardy" | "attack-defense" | "king-of-the-hill" | "mixed";
	difficulty: "beginner" | "intermediate" | "advanced" | "expert";
	registration_start: string;
	registration_end: string;
	max_participants?: number;
	participant_count: number;
	team_count: number;
	individual_count: number;
	total_challenges: number;
	scoring_mode: "static" | "dynamic" | "custom";
	created_at: string;
	updated_at: string;
}
```

## API Endpoints

### GET /api/contests

**Query Params:**

- `page=1` `limit=12`
- `search=contest_name`
- `status=upcoming|ongoing|finished`
- `format=jeopardy`
- `difficulty=advanced`
- `upcoming=true` `live=true` `finished=true`
- `has_prizes=true` `free_entry=true`
- `sort_by=newest|start_time|participants`

**Output:**

```json
{
	"success": true,
	"data": {
		"contests": [
			/* Contest objects */
		],
		"total": 200,
		"page": 1,
		"limit": 12,
		"total_pages": 17
	}
}
```

### GET /api/contests/:id

**Output:**

```json
{
	"success": true,
	"data": {
		/* Full Contest object */
	}
}
```

### POST /api/contests

**Headers:** `Authorization: Bearer <token>`
**Input:**

```json
{
	"name": "CyberChallenge 2024",
	"description": "Annual security competition",
	"start": "2024-06-15T14:00:00Z",
	"end": "2024-06-17T14:00:00Z",
	"format": "jeopardy",
	"difficulty": "advanced",
	"registration_start": "2024-05-01T00:00:00Z",
	"registration_end": "2024-06-14T23:59:59Z",
	"max_participants": 500,
	"url": "https://contest.example.com",
	"ctftime_id": 2024001
}
```

**Output:**

```json
{
	"success": true,
	"data": {
		/* Created Contest object */
	}
}
```

### PUT /api/contests/:id

**Headers:** `Authorization: Bearer <token>`
**Input:** Same as POST
**Output:**

```json
{
	"success": true,
	"data": {
		/* Updated Contest object */
	}
}
```

### DELETE /api/contests/:id

**Headers:** `Authorization: Bearer <token>`
**Output:**

```json
{
	"success": true,
	"message": "Contest deleted"
}
```

### POST /api/contests/:id/register

**Headers:** `Authorization: Bearer <token>`
**Input:**

```json
{
	"participant_type": "team", // or "individual"
	"participant_id": "team_123",
	"contact_email": "captain@team.com"
}
```

**Output:**

```json
{
	"success": true,
	"data": {
		/* Registration object */
	}
}
```

### DELETE /api/contests/:id/register

**Headers:** `Authorization: Bearer <token>`
**Output:**

```json
{
	"success": true,
	"message": "Unregistered successfully"
}
```
