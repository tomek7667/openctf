# Admin Panel & Moderation API

## Admin Models

```typescript
interface AdminUser {
	id: number;
	username: string;
	email: string;
	permission_level: "moderator" | "administrator";
	permissions: string[];
	last_login: string;
	created_at: string;
}

interface ModerationAction {
	id: number;
	action_type:
		| "warn"
		| "suspend"
		| "ban"
		| "delete_content"
		| "feature_content";
	target_type: "user" | "team" | "contest" | "writeup" | "comment";
	target_id: number;
	moderator: AdminUser;
	reason: string;
	duration?: number; // For suspensions
	created_at: string;
	resolved_at?: string;
}

interface Report {
	id: number;
	reporter: User;
	target_type: "user" | "team" | "contest" | "writeup" | "comment";
	target_id: number;
	reason: string;
	description: string;
	status: "pending" | "reviewed" | "resolved" | "dismissed";
	assigned_to?: AdminUser;
	created_at: string;
	resolved_at?: string;
}
```

## Admin Authentication

### POST /api/admin/login

**Input:**

```json
{
	"username": "admin",
	"password": "secure_admin_pass",
	"totp_code": "123456" // 2FA required
}
```

**Output:**

```json
{
	"success": true,
	"data": {
		"token": "admin_jwt_token",
		"user": {
			/* AdminUser object */
		},
		"permissions": ["manage_users", "manage_contests", "moderate_content"]
	}
}
```

## User Management

### GET /api/admin/users

**Headers:** `Authorization: Bearer <admin_token>`
**Query:** `page=1&limit=50&search=username&status=active|suspended|banned`
**Output:**

```json
{
	"success": true,
	"data": {
		"users": [
			{
				"id": 123,
				"username": "player123",
				"email": "player@example.com",
				"permission_level": "player",
				"status": "active",
				"teams_count": 2,
				"contests_participated": 15,
				"last_login": "2024-01-15T10:00:00Z",
				"created_at": "2023-06-01T00:00:00Z"
			}
		],
		"total": 2847,
		"page": 1,
		"total_pages": 57
	}
}
```

### POST /api/admin/users/:id/suspend

**Headers:** `Authorization: Bearer <admin_token>`
**Input:**

```json
{
	"reason": "Inappropriate behavior",
	"duration": 7, // days
	"notify_user": true
}
```

**Output:**

```json
{
	"success": true,
	"message": "User suspended for 7 days"
}
```

### POST /api/admin/users/:id/ban

**Headers:** `Authorization: Bearer <admin_token>`
**Input:**

```json
{
	"reason": "Repeated violations",
	"permanent": true
}
```

**Output:**

```json
{
	"success": true,
	"message": "User permanently banned"
}
```

## Implementation Notes

- Role-based access control
- 2FA requirement for admin accounts
- Audit logging for all admin actions
- Bulk operations support
- Advanced filtering and search
- Real-time notifications
- Automated moderation rules
- System health monitoring
- Configuration management
- Data export capabilities
