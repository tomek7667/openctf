# Teams Management API

## Team Model

```typescript
interface Team {
	id: number;
	name: string;
	description?: string;
	ctftime_id?: number;
	ctftime_verified_at?: string;
	logo?: string;
	verified_at?: string;
	country_code: string;
	captain?: User;
	verified_by?: User;
	members?: User[];
	// Extended fields
	member_count: number;
	statistics: TeamStatistics;
	recruitment: RecruitmentInfo;
	settings: TeamSettings;
	social_links: SocialLinks;
	privacy: "public" | "invite-only";
	created_at: string;
	updated_at: string;
}
```

## API Endpoints

### GET /api/teams

**Query Params:**

- `page=1` `limit=12`
- `search=team_name`
- `country=US`
- `min_rating=1000` `max_rating=2000`
- `is_recruiting=true`
- `sort_by=rating|members|activity|contests`

**Output:**

```json
{
	"success": true,
	"data": {
		"teams": [
			/* Team objects */
		],
		"total": 150,
		"page": 1,
		"limit": 12,
		"total_pages": 13
	}
}
```

### GET /api/teams/:id

**Output:**

```json
{
	"success": true,
	"data": {
		/* Full Team object with members */
	}
}
```

### POST /api/teams

**Headers:** `Authorization: Bearer <token>`
**Input:**

```json
{
	"name": "CyberWarriors",
	"description": "Elite security team",
	"country_code": "US",
	"ctftime_id": 12345,
	"recruitment": {
		"is_recruiting": true,
		"required_skills": ["Web", "Crypto"],
		"contact_method": "application"
	}
}
```

**Output:**

```json
{
	"success": true,
	"data": {
		/* Created Team object */
	}
}
```

### PUT /api/teams/:id

**Headers:** `Authorization: Bearer <token>`
**Input:** Same as POST
**Output:**

```json
{
	"success": true,
	"data": {
		/* Updated Team object */
	}
}
```
