# Weight Pool & Rating System API

## Models

```typescript
interface WeightRating {
	id: number;
	difficulty: number;
	captains_team: Team;
	contest: Contest;
}

interface ContestRating {
	id: number;
	rating: number;
	relevant: boolean;
	user: User;
	contest: Contest;
}

interface MonthlyDistribution {
	month: string;
	year: number;
	total_points: number;
	eligible_contests: number;
	distributed_points: number;
	remaining_pool: number;
}
```

## API Endpoints

### GET /api/weight-pool/distributions

**Output:**

```json
{
	"success": true,
	"data": [
		{
			"month": "January",
			"year": 2025,
			"total_points": 100,
			"eligible_contests": 3,
			"distributed_points": 85,
			"remaining_pool": 15
		}
	]
}
```

### GET /api/weight-pool/contests

**Query:** `month=January&year=2025`
**Output:**

```json
{
	"success": true,
	"data": [
		{
			"contest": {
				/* Contest object */
			},
			"avg_difficulty": 85,
			"avg_quality": 4.5,
			"total_ratings": 156,
			"participants": 287,
			"weight_received": 35,
			"eligible": true
		}
	]
}
```

### POST /api/contests/:id/rate-difficulty

**Headers:** `Authorization: Bearer <token>`
**Input:**

```json
{
	"difficulty": 85 // 1-100 scale
}
```

**Output:**

```json
{
	"success": true,
	"message": "Difficulty rating submitted"
}
```

### POST /api/contests/:id/rate-quality

**Headers:** `Authorization: Bearer <token>`
**Input:**

```json
{
	"rating": 4, // 1-5 scale
	"relevant": true
}
```

**Output:**

```json
{
	"success": true,
	"message": "Quality rating submitted"
}
```

### GET /api/contests/:id/ratings

**Output:**

```json
{
	"success": true,
	"data": {
		"avg_difficulty": 78.5,
		"avg_quality": 4.2,
		"total_difficulty_ratings": 45,
		"total_quality_ratings": 67,
		"weight_points": 28.5
	}
}
```

### GET /api/weight-pool/algorithm

**Output:**

```json
{
	"success": true,
	"data": {
		"description": "Weight distribution algorithm explanation",
		"factors": [
			"Contest difficulty (40%)",
			"Contest quality (30%)",
			"Participant count (20%)",
			"Organizer reputation (10%)"
		],
		"monthly_pool": 100,
		"minimum_participants": 20,
		"minimum_ratings": 10
	}
}
```

### POST /api/weight-pool/calculate/:month/:year

**Headers:** `Authorization: Bearer <token>` (admin only)
**Output:**

```json
{
	"success": true,
	"data": {
		"calculated_distributions": [
			{
				"contest_id": 123,
				"contest_name": "CyberChallenge",
				"weight_assigned": 35.5,
				"reason": "High difficulty and quality ratings"
			}
		],
		"total_distributed": 95.5,
		"remaining_pool": 4.5
	}
}
```

## Implementation Notes

- Monthly weight pool of 100 points
- Difficulty ratings from team captains only
- Quality ratings from all participants
- Minimum thresholds for eligibility
- Automated calculation at month end
- Historical tracking of distributions
- Algorithm transparency
- Admin override capabilities
