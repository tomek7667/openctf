# User Profiles & Settings API

## User Profile Model

```typescript
interface UserProfile {
	id: number;
	username: string;
	email: string;
	description?: string;
	logo?: string;
	country_code?: string;
	website?: string;
	github?: string;
	twitter?: string;
	discord?: string;
	skills: string[];
	experience_level: "beginner" | "intermediate" | "advanced" | "expert";
	looking_for_team: boolean;
	preferred_categories: string[];
	timezone: string;
	created_at: string;
	updated_at: string;
	statistics: UserStatistics;
	privacy_settings: PrivacySettings;
}

interface UserStatistics {
	teams_joined: number;
	contests_participated: number;
	total_points: number;
	best_placement: number;
	favorite_categories: string[];
	activity_score: number;
}
```

## API Endpoints

### GET /api/users/:id

**Output:**

```json
{
	"success": true,
	"data": {
		"id": 123,
		"username": "hackmaster",
		"description": "CTF enthusiast",
		"country_code": "US",
		"skills": ["Web", "Crypto", "Pwn"],
		"experience_level": "advanced",
		"looking_for_team": true,
		"statistics": {
			"teams_joined": 3,
			"contests_participated": 45,
			"total_points": 12456,
			"best_placement": 3
		}
	}
}
```

### PUT /api/users/:id

**Headers:** `Authorization: Bearer <token>`
**Input:**

```json
{
	"description": "Updated description",
	"country_code": "CA",
	"skills": ["Web", "Crypto", "Reverse"],
	"experience_level": "expert",
	"looking_for_team": false,
	"website": "https://example.com",
	"github": "hackmaster",
	"timezone": "America/Toronto"
}
```

**Output:**

```json
{
	"success": true,
	"data": {
		/* Updated UserProfile */
	}
}
```

### POST /api/users/:id/upload-avatar

**Headers:** `Authorization: Bearer <token>`
**Content-Type:** `multipart/form-data`
**Input:** File upload
**Output:**

```json
{
	"success": true,
	"data": {
		"logo_url": "https://cdn.example.com/avatars/123.jpg"
	}
}
```

### GET /api/users/:id/teams

**Output:**

```json
{
  "success": true,
  "data": [
    {
      "team": { /* Team object */ },
      "role": "captain" | "member",
      "joined_at": "2024-01-15T10:00:00Z",
      "status": "active" | "left"
    }
  ]
}
```

### GET /api/users/:id/contests

**Query:** `page=1&limit=10`
**Output:**

```json
{
	"success": true,
	"data": {
		"contests": [
			{
				"contest": {
					/* Contest object */
				},
				"team_name": "CyberElite",
				"placement": 5,
				"points": 2456,
				"participated_at": "2024-01-15T10:00:00Z"
			}
		],
		"total": 45,
		"page": 1,
		"total_pages": 5
	}
}
```

### GET /api/users/search

**Query:** `q=username&skills=Web,Crypto&looking_for_team=true&country=US`
**Output:**

```json
{
	"success": true,
	"data": [
		{
			"id": 123,
			"username": "hackmaster",
			"country_code": "US",
			"skills": ["Web", "Crypto"],
			"experience_level": "advanced",
			"looking_for_team": true,
			"activity_score": 85
		}
	]
}
```

### PUT /api/users/:id/privacy

**Headers:** `Authorization: Bearer <token>`
**Input:**

```json
{
  "profile_visibility": "public" | "teams_only" | "private",
  "show_email": false,
  "show_real_name": false,
  "show_statistics": true,
  "show_team_history": true,
  "allow_team_invites": true
}
```

**Output:**

```json
{
	"success": true,
	"message": "Privacy settings updated"
}
```

### POST /api/users/:id/change-password

**Headers:** `Authorization: Bearer <token>`
**Input:**

```json
{
	"current_password": "oldpass123",
	"new_password": "newpass456"
}
```

**Output:**

```json
{
	"success": true,
	"message": "Password changed successfully"
}
```

### POST /api/users/:id/change-email

**Headers:** `Authorization: Bearer <token>`
**Input:**

```json
{
	"new_email": "newemail@example.com",
	"password": "currentpass123"
}
```

**Output:**

```json
{
	"success": true,
	"message": "Verification email sent to new address"
}
```

### POST /api/users/:id/verify-email

**Input:**

```json
{
	"token": "verification_token"
}
```

**Output:**

```json
{
	"success": true,
	"message": "Email verified successfully"
}
```

### DELETE /api/users/:id

**Headers:** `Authorization: Bearer <token>`
**Input:**

```json
{
	"password": "currentpass123",
	"confirmation": "DELETE_MY_ACCOUNT"
}
```

**Output:**

```json
{
	"success": true,
	"message": "Account deleted successfully"
}
```
